Pasos para ejecutar el proyecto

1-Clonar o descargar el repositorio.

2-Abrir el proyecto en Apache NetBeans desde la carpeta que contiene pom.xml.

3-Crear en MySQL la base de datos tienda y sus tablas correspondientes.

4-Configurar el usuario y la contraseña de MySQL en la clase Conexion.java.

5-Esperar a que Maven descargue las dependencias necesarias.

6-Ejecutar la clase VentanaInventario.java para abrir la interfaz gráfica.
